# ĐỒ ÁN

Dự án website bán thiết bị vệ sinh cao cấp.

## Công nghệ sử dụng
- Frontend: Next.js 14
- Backend: NestJS
- Database: MySQL + Prisma
- Styling: Tailwind CSS

## Cài đặt

### Backend
```bash
cd backend
npm install
npx prisma db push
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
